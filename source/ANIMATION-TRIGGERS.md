# 小蕾米动作触发规则

`animation-triggers.json` 是小蕾米的运行器适配配置，不改变 Codex v2 所要求的 `pet.json` 格式。

原本的 `jumping` 行已经替换为用户提供的 `smug.gif`，画面表现为小蕾米抱着画板、闭眼得意的完成庆祝姿态；保留 `jumping` 这个原生状态名只是为了满足 Codex v2 的固定图集行结构。

| 事件 | 动作 | 播放方式 |
| --- | --- | --- |
| 启动桌宠 | 挥手 | 播放一次 |
| 鼠标移入 | 挥手 | 播放一次，10 秒冷却 |
| 点击小蕾米 | 挥手 | 播放一次，2.5 秒冷却 |
| 任务完成 | 完成庆祝（smug） | 播放一次，3 秒冷却 |
| 收到重要通知 | 完成庆祝（smug） | 播放一次，5 秒冷却 |
| 双击互动 | 完成庆祝（smug） | 播放一次，3 秒冷却 |
| 互动成功 | 完成庆祝（smug） | 播放一次，3 秒冷却 |

触发动作完成后，运行器应恢复触发前的状态；如果没有可恢复状态，则回到 `idle`。跳跃优先级高于挥手，避免重要事件被普通鼠标事件覆盖。

注意：当前项目只有宠物素材包，没有鼠标监听、任务状态监听或通知监听程序。因此这个文件已经准备好触发映射，但需要桌宠运行器读取它，动作才会在真实事件中自动播放。
